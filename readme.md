A snapshot of the binaries for the latest versions of the Sequencer Powerups NINA plugin before removal.

## How to install

1. Open a terminal in this repository folder.

2. Copy the files for your NINA version.

### NINA 3.2

```
xcopy /E /I "3.2\Sequencer Powerups" "%LOCALAPPDATA%\NINA\Plugins\3.0.0\Sequencer Powerups"
```
### NINA 3.3

```
xcopy /E /I "3.3\Sequencer Powerups" "%LOCALAPPDATA%\NINA\Plugins\3.0.0\Sequencer Powerups"
```
